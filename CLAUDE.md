# PRECISUR — CONTEXTO RAÍZ DEL PROYECTO WEB

## Regla principal

Antes de modificar, crear o eliminar código, lee los documentos de contexto referenciados abajo.

Este proyecto NO es una landing page comercial convencional.

Es una plataforma web institucional y tecnológica diseñada para presentar PRECISUR ante organismos públicos, potenciales aliados estratégicos, instituciones académicas y actores del ecosistema agropecuario de Uruguay.

El objetivo principal no es únicamente explicar qué es Precisur.

El objetivo es generar una conclusión clara en el visitante:

> "Este proyecto tiene una base tecnológica seria, resuelve un problema real del sector agropecuario y merece apoyo para continuar su desarrollo y validación."

# Principio de diseño

La web debe sentirse como:

* una empresa deep-tech agrícola
* un proyecto de ingeniería avanzada
* una iniciativa científica uruguaya
* una plataforma tecnológica con potencial nacional
* un sistema en desarrollo que busca validación y escalamiento

NO debe sentirse como:

* una landing page genérica de startup
* una página llena de tarjetas flotantes
* una web corporativa tradicional
* una presentación escolar
* una promesa exagerada de inteligencia artificial
* una empresa que afirma tener capacidades que todavía no posee

---

# Principio de honestidad científica

Nunca afirmar:

* precisión experimental no validada
* resultados de campo inexistentes
* reducción porcentual de deriva sin evidencia experimental
* certificaciones no obtenidas
* integración institucional inexistente
* capacidades futuras como si ya estuvieran disponibles

Distinguir siempre entre:

1. IMPLEMENTADO
2. VALIDADO EN SOFTWARE
3. PENDIENTE DE VALIDACIÓN EXPERIMENTAL
4. VISIÓN FUTURA

La honestidad técnica aumenta la credibilidad institucional.

---

# Objetivo emocional de la experiencia

El visitante debe recorrer esta secuencia mental:

1. "El problema es importante."
2. "La agricultura necesita mejores herramientas."
3. "Esto no es una idea superficial."
4. "Hay ingeniería real detrás."
5. "La tecnología ya tiene una base construida."
6. "Uruguay podría desarrollar capacidad propia."
7. "Con apoyo institucional esto podría escalar."
8. "Tiene sentido apoyar este proyecto."

---

# Regla de implementación

Antes de construir una nueva sección:

1. Identificar qué pregunta debe responder.
2. Identificar qué evidencia visual o técnica la respalda.
3. Determinar qué emoción debe generar.
4. Construir la experiencia visual.
5. Verificar que no existan afirmaciones científicas sin respaldo.

Nunca agregar elementos únicamente porque "se ven modernos".

Cada elemento visual debe tener una función narrativa.
