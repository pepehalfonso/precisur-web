# Convenciones — Web Precisur

## Filosofía visual

PRECISUR no debe parecer una startup SaaS.

Debe sentirse como una combinación entre:

* laboratorio tecnológico
* centro de control
* ingeniería aeroespacial
* agricultura de precisión
* visualización científica

---

# Paleta conceptual

Usar el sistema visual existente de Precisur como referencia.

Semántica:

* Verde → favorable / agricultura / acción
* Cyan → datos / meteorología
* Amarillo → atención
* Naranja → revisión
* Rojo → riesgo
* Violeta → incertidumbre
* Oscuros → profundidad tecnológica

No usar colores arbitrarios.

Cada color debe comunicar significado.

---

# Tipografía

Priorizar:

* títulos geométricos y contundentes
* textos institucionales altamente legibles
* números técnicos monoespaciados cuando sea apropiado

Evitar tipografías excesivamente futuristas.

---

# UI

PROHIBIDO abusar de:

* tarjetas blancas
* bordes redondeados gigantes
* glassmorphism en todo
* gradients decorativos sin función
* iconos flotantes
* dashboards falsos

Preferir:

* grandes espacios
* tipografía fuerte
* visualizaciones
* líneas
* grids
* animaciones físicas
* mapas
* diagramas

---

# Animaciones

Las animaciones deben comunicar información.

Ejemplos válidos:

* partículas desplazadas por viento
* vectores meteorológicos
* propagación de concentración
* construcción progresiva de rutas
* conexión entre sistemas
* transición modelo → campo

Evitar animaciones decorativas.

---

# Scroll

El scroll debe sentirse cinematográfico.

Utilizar:

* sticky sections
* parallax moderado
* progresión narrativa
* transiciones suaves

Nunca sacrificar rendimiento por animación.

---

# Accesibilidad

Toda información importante debe existir también como texto.

No depender exclusivamente de:

* color
* animación
* hover

---

# Responsive

Mobile-first.

Pero la experiencia desktop es prioritaria para presentación institucional.

La web debe funcionar perfectamente en:

* 1440px
* 1280px
* tablets
* móviles

---

# Regla de oro

Si un componente podría aparecer indistintamente en una landing de criptomonedas, una fintech o una aplicación de IA genérica, probablemente no pertenece a Precisur.
